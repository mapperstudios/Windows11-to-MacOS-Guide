# V0.5.1 Public Beta 1
The macOS desktop has a specific quality that a lot of Windows users find appealing: a minimal dock at the bottom, clean translucent elements, no icons cluttering the wallpaper, and a sense that each interface element has been thought about. You do not need to buy a Mac to get close to that aesthetic. With the right combination of small, focused tools, Windows 11 can be transformed convincingly.

This guide goes layer by layer — dock, taskbar, window chrome, wallpaper, icons, and finally a desktop widget layer for the information that macOS users often miss when they switch platforms. Everything here is reversible and none of it requires editing system files.

We will not use any type of applications that require you to pay so everyone can use this. Also, make sure you have enough RAM on your computer. Please always check and see the updated version of the guide as some mods don't work after some time. We will not use too much of your storage so don’t worry! Thank you!

Note: Windows 11 is required.

## Step 1: Install Windhawk
Windhawk is a free, open-source customization tool and marketplace for Windows that lets you modify the appearance and behavior of your operating system. It takes up very little space and also only changes little modifications.
Install Windhawk here: [https://windhawk.net/](https://windhawk.net/). 
In the webpage, click download! The exe file will automatically download. Afterwards, you should install it, click the "Install" button and it should work. The app should pop up automatically.

## Step 2: Changing from Windows taskbar to MacOS dock
Now that you installed Windhawk, we should start the modifications! The dock of the MacOS system is somewhat where 80% users can tell and want on their Windows 11 system. Instead of the traditional way of using "Windows 11 Taskbar Styler", which lags a lot in some computers, we are using "MacOS Style Dock". This mod is both more realistic and not too laggy. 

In Windhawk, downloading a mod is very easy. First, click the "Install" button. An "Accept risk and install" button should come out with a "Proceed with care" message. When you install it, you can see what the mod changes!

Now, go to settings of the mod. You can see a "Dock Panel" section. Look for size and change it to 30. This should make the dock look more MacOS. Next, go to the "Dock Items" section. Disable the "Divider after File Explorer" choice.

Tip: If you are using a high-resolution 4K display, a size of 30 might look a bit too tiny. Feel free to bump it up to 40 or 45 depending on your screen resolution so it feels comfortable to click.

## Step 4: Dock Animations and Extra Configurations
Go back to Windhawk now, find the "Taskbar Dock Animation Plus" mod. Install it like how you did before. After you install, find the "Maximum scale (%)" setting, set it to 130. This is around it. 

You should have noticed the separator before the Finder app I provided in the image before. Here is the trick, install the "Taskbar Icon Separators" in Windhawk and right-click the dock. You should see the "Add Separator" choice. Now, place the choice to your desired position!

Now, we need to hide the start button. Search for the "Hide Start Button" mod and install it. Also, if you prefer, install the "Taskbar tray system icon tweaks" mod so your system tray will be cleaner, keep the language bar since it will be not found in the TopBar part later. This is around all for these animations and other configs.

## Step 5: TopBar
Since if we use the same TopBar as MacOS, we need to either pay or download big exe files in our PC. Now go to find the "TopBar for Windows" mod. Install it and find the "Theme" settings, change it to "NoIslands" so it matches the MacOS style. You can now see a settings button in the TopBar, head to it! Go to the "Import/Export" Part. Select "Import json..." and go to [https://drive.google.com/file/d/1m5d-xcpdqtYzMBEVfrAe6r23DEYf1UjV/view?usp=sharing](https://drive.google.com/file/d/1m5d-xcpdqtYzMBEVfrAe6r23DEYf1UjV/view?usp=sharing) and download the json file. ## Step 6: UI Fixes and Start menu
Now go back to Windhawk, go ahead and install the "Genie Animation Mod". This mod lets you have a genie-like minimize animation. Using this, you will get MacOS styled animations. Now install "MacOS Minimize Animation", this gets even better animations for you! Also install "Dark mode context menus" for dark mode to be more correct. Now install "Translucent Windows
" so you can have liquid/frosted glass UI. Include the "WinUI Context Menu Animation" too so the right-click animation looks better. In settings select "Translucent Windows compatibility mode" to on.

For the Start menu, since their is no Start menu in MacOS. We will still Mac it up! Install "Compact Start Menu" and you can see it more "Mac-ed". Now, don't forget the "Windows 11 Start Menu Styler", use the liquid glass (For redesigned Start menu)
